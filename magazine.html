Editor’s note

On rereading one’s own brief

The first magazine was a handsome README. It walked the routes, listed the env vars, and concluded that Vercel plus Neon plus Anthropic was “the right size.” That is true in the boring sense: the code runs there, the free tiers cover the volume, a measured day finishes in about ninety seconds. It is not a thought. A thought would ask what job each vendor is being asked to do, whether those jobs want the same computer, and which missing piece is product rather than platform.

This issue starts from the code as it is — advance() in src/pipeline.ts, the lease in src/lib/lock.ts, rankScore() in the heuristic module, the 60-item corpus cap, the 13:00 UTC window — and argues. If you only need the checklist, skip to the back. If you are about to spend money on a new vendor because a blog post said “real workers don’t run on Vercel,” stay for the middle.

01 — The product is a newspaper

Trendwire is not a chatbot over a firehose and it is not “AI-powered HN.” It is a dated issue. The unit of work is one day. After publish, the site is a newsstand: it sells copies of something already written. Pages do not re-fetch Hacker News. They read rows. That split — typesetter once, newsstand many times — is the whole architecture. Everything that looks like a platform quirk is a consequence of running the typesetter inside the newsstand’s request handler.

You did not build a feed. You built a paper that refuses to stay open after the press run.

The reader it assumes has already left X. The system prompt says so in the first sentence. The X tier is therefore not “our Twitter scraper.” It is a braid of secondhand paths — Techmeme, newsletters, optional Exa, racing Nitter-style mirrors for five accounts — because the product thesis is that the industry argument leaks onto the open web with a few hours’ lag. If that thesis is wrong, Exa will not save you. If it is right, you do not owe $200/month to xAI’s API.

The window closes at 13:00 UTC. That is 6:00 Pacific, 9:00 Eastern, 14:00 London. It is a morning paper for the United States and an afternoon paper for Europe. Backfills for a date use the same close, so 2026-08-15 is a real issue, not “whatever was lying around when I clicked.”

There is no email. RSS exists. For a public archive that is fine. For a paper whose audience is you, delivery is the product. A site you remember to open is a hobby. A site that arrives is a habit. The missing vendor, if there is one, is Resend — not Fly.

02 — Ranking is a constitution

Most “digest” tools rank by points. Trendwire ranks by a formula you should be able to recite, because it is the editorial board:

score      = ln(1 + points)      × 10
comments   = ln(1 + comments)    ×  6
corroboration = (sources − 1)    × 25
velocity   = min(points/hour, 100) × 0.4
people     = +8 if the item is on the people beat

Logarithms flatten HN giants. The 25-point corroboration term does the opposite of flattening: one extra independent source is worth more than going from 20 points to 400. Two extra sources beat a thousand-point thread. That is a policy. It says consensus over virality. It will systematically underweight a brilliant Lobsters-only argument and overweight a mediocre story that Techmeme, The Verge, and HN all carried. For “what the industry argued about,” that bias is correct. For “what a tasteful editor would have noticed,” it is not. Do not “fix” it without deciding which paper you are.

Two more statutes. The people beat is guaranteed up to 15 seats in a 60-item corpus so a busy model-release day cannot erase hiring. And 60 is not a round number: at 120 items a live Sonnet call did not return in ten minutes, which on Vercel is a killed function and a blank day. At 60 it returns in about 40 seconds. Dedup means the top 60 already are the day. Raising SYNTH_MAX_CORPUS without raising LLM_TIMEOUT_MS and measuring is how you skip an issue.

Confidence on people moves is a column — confirmed, reported, chatter — not an adjective in the prose. The UI can refuse to dress chatter in the same type as a resignation letter. The heuristic path is forbidden from marking anything higher than chatter. That is the one place the code is more honest than a human intern would be.

The dishonest place is the other fallback. If the model is missing or throws, the paper still publishes: term clusters named like “deepseek / harness / plugin,” with an intro that admits it. A newspaper that typesets word-clouds to keep the streak is not a newspaper. For a personal paper I would rather serve a ranked wire list under a red banner, or a 503. Failed-open is a product choice. It is not a virtue.

03 — Anatomy of a press run

Seventeen adapters write into raw_items. They are not allowed to throw into the runner. Each reports ok, empty, failed, or skipped into run_sources. Progress is that log. There is no cursor column. Resume cannot skip a source because batch three died; the next tick asks the log what already happened.

Vercel Cron   13:00 UTC        GitHub Actions   every 15 min
      │                              │
      └────────► /api/cron/digest    /api/tick ◄──
                       │               │
                       └───────┬───────┘
                               ▼
                    lease row (not advisory lock)
                    ingest pending sources in 4s
                    stop at 240s, or synthesize
                    publish · release

Both doors call advance(). There is no self-fetch. An earlier design chained chunks over HTTP. Vercel may freeze a function the moment it responds; an un-awaited fetch can die inside the isolate. waitUntil counts against the same 300-second ceiling, so chaining bought nothing. The 240-second internal budget leaves ~50 seconds for teardown. Budget is enforced only after at least one batch, otherwise a slow setup livelocks: every tick returns having done nothing, the log never changes, tomorrow looks like today.

The lock is a row named digest-pipeline: insert, or steal only if expires_at is past. Neon’s pooler is PgBouncer in transaction mode. A session pg_advisory_lock taken through it can outlive the logical connection. A lease expires if the isolate is killed. That is not distributed-systems theater. It is the Postgres you actually have.

Dedup is canonical URL (strip tracking, alias twitter.com/nitter to x.com) then a 32-character sha256 of normalized title plus a body prefix. The richest score wins. The duplicate count is kept, because it is the corroboration term above.

Reddit from Vercel is usually a 403. That is Reddit blocking unauthenticated JSON from datacenter IPs. Fly and AWS see the same wall. The adapter reports skipped, which is the honest status. The fix is an OAuth app, about an hour of work, not a new host.

04 — Would I use another service?

The only question this issue exists to answer

Separate the jobs. The newsstand is a Next.js App Router site with time-based revalidation (five minutes on /, an hour on a dated issue). The typesetter is a 90-second job that speaks TCP Postgres, hits seventeen HTTP APIs, and makes one model call. Those jobs want different computers. Trendwire runs both in one Vercel function. That is the clever hack and the original sin.

Verdict, after thinking about it

Keep Neon. Keep Vercel as the newsstand. Keep Anthropic with OpenAI behind it. Keep GitHub Actions as the second clock. Do not add Redis, S3, a vector database, Inngest, Cloudflare Workers, PlanetScale, or the X API. The one host-side change I would consider later is moving the typesetter off the request/response cycle and into Actions in-process. The one vendor I would add soon is Resend. The one credential I would add sooner is Reddit OAuth. The highest-ROI “service” that is not a vendor is a warmup curl five minutes before press time, because the free-tier architecture is at war with a single morning reader.

Neon stays

The schema is ordinary Postgres: unique indexes, a lease row, versioned SQL in drizzle/. You need a pooled URL at runtime (transaction-mode pooler, prepare: false in postgres.js) and a direct URL for migrations. The Vercel Marketplace sets both. Supabase is also Postgres plus Auth and Realtime this app does not use. RDS does not sleep and costs ~$15/month — better for latency, worse for a $0 hobby. PlanetScale is MySQL and a rewrite. Turso is the wrong lock model. PGlite is the local harness and must never be production. Neon is the correct managed Postgres for this shape.

The catch is the free compute suspend after five idle minutes. Caching helps everyone except the first reader. The first reader of a daily paper is you, at breakfast. That is the cold-start paradox: the architecture is optimized for zero cost on a traffic pattern this product does not have. A GitHub Action that GETs /api/status at 12:55 UTC costs nothing and does more for the reading experience than switching databases.

Vercel stays for HTTP. It is the wrong factory floor.

Hobby cron is once per day and may fire anywhere in the hour. Overlaps are not deduped. Returning while work is in flight can freeze the isolate. Fluid compute gives 300 seconds even on Hobby, which is why a 90-second run fits and why the resume path is for slow days, not the happy path. The lease, the run log, the “no self-fetch” rule, and the GitHub tick are all translations of those constraints into code. They are good translations. They are also a tiny durable-execution runtime you wrote because the platform would not.

Cloudflare Workers are the wrong runtime: isolate CPU budgets, and TCP postgres.js is not native (Hyperdrive exists; you would rewrite the data layer for a job that already finishes). Netlify is another newsstand. Railway and Render want a process. Fly Machines would be a respectable typesetter — boot, run, sleep — if you were paying. At $0, GitHub Actions is the Fly Machine you already have: six-hour timeout, no freeze, 2,000 minutes/month, and a workflow that currently wastes itself by HTTP-calling Vercel.

The tick workflow is a second clock attached to the wrong worker. The worker should move to the clock, not the other way around.

runToCompletion() already exists for the local harness: up to twelve passes at ten minutes each, no function ceiling. Pointing Actions at that, with DATABASE_URL set to Neon, would make Vercel a reader. You would write a thin scripts/run-prod.ts (the local script is PGlite-shaped). Until 300 seconds actually bites — it has not, at ~90s — calling /api/tick is the zero-code version of the same idea. I would not delay the first issue for the in-process cutover. I would also not pretend Vercel is a good place to run a press.

Inngest and Trigger.dev productize exactly this: checkpoint, resume, single-flight. They would delete lock.ts and a chunk of advance(). At one job per day they are a second monthly bill and a second dashboard to replace 200 lines that are already tested. The tests are the point: contention (one of four wins), steal-on-expiry, release-on-throw, every source ingested once across 1ms-budget resumes. You do not buy a product to replace a passing test suite for a job that runs while you sleep.

The model stays. The X API does not get purchased.

One call, ~20k input tokens, ~40 seconds. Gemini and OpenRouter are first-class; Anthropic and OpenAI still work. Configured keys are tried in order (gemini → openrouter → anthropic → openai) unless you pin with LLM_PROVIDER. A 120-second abort so a stalled provider cannot eat the whole 300 seconds and leave an empty run log. Heuristics then still have time — which, as argued above, should perhaps publish a wire list rather than clusters.

Exa is optional semantic search over x.com and over announcement-shaped pages. Skip the key and those two sources report skipped; Techmeme and the newsletters still carry the tier. The official X API is a luxury subscription for a product whose thesis is that you do not need it. Mirrors racing karpathy, sama, simonw, swyx, emollick will fail often. That is priced in.

05 — What I would actually change

Order is the thought. Do not start with a platform migration.

  1. Ship the paper on the current stack. Import skyspeak/socialproof, attach Neon, set CRON_SECRET and a model key, migrate on the direct URL, kick /api/cron/digest. Read the first issue. Everything below is for issue two.
  2. Reddit OAuth. Highest-ROI source. It is a credential, not a host. Until then r/LocalLLaMA — the open-model conversation that often leads Twitter by a day — is dark from production.
  3. Warmup. Schedule Actions to hit /api/status at 12:55 UTC. Wake Neon before the press run and before you. Free.
  4. Resend on persist. One email, the day’s headline and intro, a link home. RSS is for people who already have readers. You probably do not.
  5. Failed synthesis should not wear the issue’s clothes. A ranked list plus a banner, or no publish. The heuristic clusters exist to keep the streak. Streaks are for dashboards.
  6. If a day ever dies at 290 seconds, move runToCompletion() into Actions against Neon and leave Vercel as the newsstand. Not before.

Uptime: point Better Stack or Cronitor at /api/status. It is unauthenticated, counts only, and returns 503 when the newest digest failed or Postgres is unreachable. That endpoint was designed for a monitor. Use it.

06 — Turning it on

Fifteen minutes if the accounts exist. GitHub is done. You still need Vercel and Neon. Do not open the site until step 6. Missing schema looks like a broken app. Missing CRON_SECRET in production makes both pipeline routes 401 — fail closed, on purpose.

  1. Import the repo. Vercel, Next.js preset, skyspeak/socialproof. First deploy may go green. Ignore the empty state.
  2. Attach Neon via the Marketplace. Storage → Create Database → Neon, Free, a region near you. This sets DATABASE_URL (pooled) and DATABASE_URL_UNPOOLED (direct). Prefer this to copying strings from neon.tech.
  3. Secrets, Production (and Preview if you care). CRON_SECRET = openssl rand -hex 32. At least one of GEMINI_API_KEY, OPENROUTER_API_KEY, ANTHROPIC_API_KEY, OPENAI_API_KEY. Optional LLM_PROVIDER=gemini,openrouter. NEXT_PUBLIC_SITE_URL as the origin, no trailing slash. EXA_API_KEY only if you want those two sources live.
  4. Migrate from this machine against the direct string. cp .env.example .env, then npm install && npm run db:migrate. Errors about SET or prepared statements mean you are on the pooler. Stop.
  5. Redeploy production so the runtime has the env. Marketplace variables sometimes attach to a deployment that already started.
  6. Press the first issue rather than waiting until 13:00 UTC:
    curl -H "Authorization: Bearer $CRON_SECRET" https://HOST/api/cron/digest
    Want outcome: "synthesized", a provider name, elapsed around one to two minutes. out_of_budget is not failure — call /api/tick.
  7. Verify. GET /api/status → database: "connected", llmConfigured: true, latest.status: "published". Then /, /archive, /feed.xml.
  8. On Hobby, enable the tick. Actions secrets: SITE_URL (no slash) and the same CRON_SECRET. Manual date input is how you backfill. On Pro you may delete the workflow and cron more often; both routes share advance().
